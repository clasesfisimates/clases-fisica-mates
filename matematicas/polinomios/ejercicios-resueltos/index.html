Reconocer un cuadrado perfecto

Escribe 4x² + 4x + 1 como una identidad notable.

4x² = (2x)²1 = 1²

Ficha de identidades notables y factorización · ejercicio 2

Ver resolución paso a paso

  1. Identifica las dos piezas cuadradas

    Los extremos se pueden escribir como cuadrados de 2x y de 1.

    4x² = (2x)², 1 = 1²

  2. Comprueba el doble producto

    Los dos rectángulos tienen la misma área. En la identidad, suman el término central.

    2 · (2x) · 1 = 4x

  3. Aplica el cuadrado de una suma

    Sustituye a por 2x y b por 1.

    a² + 2ab + b² = (a + b)² ⇒ 4x² + 4x + 1 = (2x + 1)²

Resultado. La identidad es (2x + 1)².

Dividir un cúbico entre un polinomio de grado dos

Divide x³ + 6x² + 8x + 7 entre x² + x + 1. Escribe el cociente y el resto.

Grado del dividendo: 3Grado del divisor: 2

Ficha de identidades notables y factorización · ejemplo de la pizarra de división

Ver resolución paso a paso

  1. Obtén el primer término del cociente

    Divide x³ entre x². Luego multiplica el divisor entero por x y resta el producto.

    x³ / x² = x

    (x³ + 6x² + 8x + 7) − (x³ + x² + x) = 5x² + 7x + 7

  2. Obtén el segundo término

    Divide 5x² entre x². Multiplica el divisor por 5 y vuelve a restar.

    5x² / x² = 5

    (5x² + 7x + 7) − (5x² + 5x + 5) = 2x + 2

  3. Detente y comprueba

    El resto tiene grado 1, menor que el grado del divisor. Puedes reconstruir el dividendo multiplicando y sumando.

    (x² + x + 1)(x + 5) + (2x + 2) = x³ + 6x² + 8x + 7

Resultado. Cociente x + 5 y resto 2x + 2.

Sacar factor común y localizar una raíz doble

Factoriza 2x³ + 8x² + 8x y encuentra sus raíces y sus multiplicidades.

Factor común: 2x

Ficha de identidades notables y factorización · ejercicio 4, apartado f

Ver resolución paso a paso

  1. Extrae el factor común

    Los tres términos se pueden dividir entre 2x.

    2x³ + 8x² + 8x = 2x(x² + 4x + 4)

  2. Reconoce la identidad dentro del paréntesis

    Los cuadrados son x² y 2². El doble producto es 4x.

    x² + 4x + 4 = (x + 2)²

  3. Iguala a cero cada factor

    Un producto se anula cuando alguno de sus factores vale cero.

    2x = 0 ⇒ x = 0

    (x + 2)² = 0 ⇒ x = −2

Resultado. La factorización es 2x(x + 2)². Las raíces son 0 (simple) y −2 (doble).

Sumar fracciones con denominadores distintos

Simplifica 1 / (x − 3) + 2 / (x² − 9). Indica los valores de x que quedan fuera del dominio.

x² − 9 = (x − 3)(x + 3)

Variante del ejemplo guiado de fracciones algebraicas

Ver resolución paso a paso

  1. Factoriza y escribe las restricciones

    El segundo denominador es una diferencia de cuadrados. Antes de operar, excluye los valores que anulan cualquiera de los denominadores originales.

    x² − 9 = (x − 3)(x + 3) ⇒ x ≠ 3 y x ≠ −3

  2. Usa un denominador común

    Multiplica el numerador y el denominador de la primera fracción por x + 3.

    (x + 3) / [(x − 3)(x + 3)] + 2 / [(x − 3)(x + 3)]

  3. Suma los numeradores

    El denominador común se conserva. Comprueba si el numerador comparte algún factor con él.

    [(x + 3) + 2] / [(x − 3)(x + 3)] = (x + 5) / (x² − 9)

Resultado. La suma es (x + 5) / (x² − 9), con x ≠ −3 y x ≠ 3.
